# Blender and HAVEN

HAVEN has a fast Three.js scene from the shared spec and Blender-exported GLBs. The dashboard reuses both; it does not require Next.js.

## Live scene

1. Open the HAVEN scene generated by `blender/build_blackwell.py`.
2. In Blender's Scripting workspace, run `blender/haven_live.py`.
3. Open the HAVEN sidebar and connect to the backend.
4. When Clerk is enabled, provide an administrator session token through `HAVEN_BLENDER_TOKEN` in Blender's environment. Session tokens expire; refresh when necessary. Do not embed the Clerk secret API key in a Blender file.

The bridge reads the existing backend world. The dashboard can display the exported model without Blender running.

## MCP

The community [MCP for Blender](https://github.com/ahujasid/mcp-for-blender) project provides a Blender add-on and companion MCP server. Follow its current installation instructions, enable the add-on, start its local server and register its MCP process in the editor. Reload the tool connection. The default add-on port is 9876; keep it local.

Installing Blender alone does not expose MCP tools. This session did not discover callable Blender MCP tools. Existing GLB rendering works independently of that connection.
